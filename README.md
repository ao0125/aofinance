# aofinance — 金融ブログ ホームページ

## プロジェクト概要

**aofinance** は「お金をもっと身近に。人生をもっと豊かに。」をコンセプトとした金融ブログです。  
Cloudflare Pages でのホスティングを前提とした静的ウェブサイトです。

---

## Cloudflare Pages デプロイ手順

1. GitHub リポジトリにソースをプッシュ
2. Cloudflare Pages ダッシュボードで「新しいプロジェクトを作成」
3. リポジトリを接続し、ビルド設定はなし（静的ファイルのため）
4. デプロイ完了後、カスタムドメインを設定（任意）

---

## 開発メモ

- SPA（シングルページアプリ）構成で、URL ハッシュ（`#home`, `#articles`, `#quiz`）でタブを切り替え
- Cloudflare Pages は静的ファイルをそのままホストできるため、ビルドステップ不要
- CDN リソースはすべて外部 URL から読み込むため、オフライン環境では一部表示が崩れる場合あり
